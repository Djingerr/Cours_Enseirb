## Introduction

Ce cours présente les outils essentiels utilisés dans le développement logiciel professionnel en langage C.  
Au-delà de l’écriture de code, il vise à apprendre **comment construire, organiser, tester et maintenir un programme**.

Il s’inscrit dans une démarche pratique : comprendre les outils qui permettent de développer des programmes robustes et collaboratifs.

---

## Objectifs d’apprentissage

À l’issue de ce cours, vous devrez être capable de :

- être plus à l’aise avec la programmation en **C**
- utiliser des outils pour **déboguer efficacement**
- automatiser la compilation avec **Make**
- gérer les versions d’un projet avec **Git**
- adopter des pratiques professionnelles de développement

Ces compétences sont indispensables pour :
- les projets académiques
- le travail en équipe
- le développement logiciel réel

Avant ce cours, vous devez maîtriser :

Ces notions sont indispensables pour comprendre les outils présentés.

## Thématiques principales du cours

Le cours s’organise autour de cinq axes fondamentaux :

1. Construction de bibliothèques
2. Automatisation avec Makefile
3. Déverminage (debugging)
4. Gestion de version avec Git
5. Outils et bonnes pratiques de développement

---

## Pourquoi ces outils sont essentiels ?

Programmer ne consiste pas seulement à écrire du code.

Un développeur doit savoir :

- structurer un projet
- automatiser les tâches répétitives
- détecter et corriger les erreurs
- collaborer efficacement
- maintenir et faire évoluer un logiciel

👉 Ces outils transforment un programmeur débutant en développeur efficace.

---

## Définitions clés

**Compilation** — transformation du code source en programme exécutable.

**Débogage (debugging)** — processus de détection et correction des erreurs.

**Gestion de version** — suivi et gestion des modifications du code dans le temps.

**Automatisation** — exécution automatique de tâches répétitives (compilation, tests…).
